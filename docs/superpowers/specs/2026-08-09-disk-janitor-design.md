# disk-janitor 设计文档（一期）

> 日期：2026-08-09  
> 状态：已批准（用户确认一期范围 + 回收站删除）

## 目标

轻量、高速的 Windows 磁盘分析与清理工具。产品愿景对齐商业清理软件（C），分三期交付；**一期**解决「看不到真实大小、难按大小/时间找垃圾」的核心痛点。

## 非目标（一期不做）

- 一键「智能清理」营销式全盘自动删
- 重复文件 / 卸载残留 / 开机启动项（三期）
- 常见垃圾规则建议列表（二期）

## 技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 语言 | Rust | 扫盘快、单文件分发、内存可控 |
| UI | egui / eframe | 无 Electron，体积小，原生窗口 |
| 删除 | 系统回收站 | 误删可恢复（用户选 A） |
| 平台 | Windows 优先 | C 盘清理主场景 |

## 架构

```
┌─────────────────────────────────────┐
│  UI (eframe)                        │
│  盘符选择 · 树 · 列表 · 排序 · 搜索  │
└──────────────┬──────────────────────┘
               │ 命令 / 快照
┌──────────────▼──────────────────────┐
│  ScanEngine                         │
│  多线程遍历 · 聚合目录大小 · 进度    │
└──────────────┬──────────────────────┘
               │
┌──────────────▼──────────────────────┐
│  TrashService                       │
│  移到回收站 · 确认 · 系统路径警告    │
└─────────────────────────────────────┘
```

## 功能（一期）

1. **扫盘**：选盘符或任意文件夹；后台扫描；进度条；可取消  
2. **树 + 列表**：文件夹显示聚合占用；文件显示自身大小  
3. **排序**：大小 / 修改时间 / 名称（升/降序）  
4. **过滤**：按名称子串快速过滤当前视图  
5. **删除**：多选后「移到回收站」；确认对话框显示路径与合计大小；Windows / Program Files 等路径二次警告  
6. **跳过**：无权限目录记为跳过，不中断整次扫描；尽量不跟随会循环的 junction（或限制深度）

## 性能要求

- 并行目录遍历（rayon / 工作队列）
- UI 不阻塞；结果增量刷新
- 排序/筛选基于内存树，不重复扫盘
- Release 构建；目标单 EXE 可分发

## 安全

- 默认进回收站，不永久删除
- 删前确认
- 对明显系统路径二次确认

## 后续期

- **二期**：Temp / 缓存 / 下载大文件等规则建议  
- **三期**：重复文件、卸载残留、开机项  

## 验收

- `cargo build --release` 成功  
- 能扫描用户目录并按大小排序  
- 测试文件可移入回收站并在资源管理器回收站中看到
