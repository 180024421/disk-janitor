## 下载

- 便携版：`DiskJanitor-0.9.7.exe`

## 激活

1. 打开软件，在激活页粘贴卡密并激活。
2. 同一张卡最多 3 台设备。
3. 激活后会缓存本地票据，短期内离线仍可打开。
4. 卡密过期或被冻结后，软件会自动回到激活页，无法继续使用主功能。

## 总览页

1. **顶部**：左侧「共发现 … 可清理文件」；右侧「刷新扫描」「一键清理」。
2. **磁盘卡片（整行）**：圆环 + 进度条 + 已用/可用/总容量；底栏「加入队列 / 选为路径 / 极速 / 扫描」。
3. **多盘排队**：勾选「加入队列」后用标题栏「极速已选 / 扫描已选」。
4. **可清理项目**：扫过垃圾后出现在磁盘下方，点行进入「垃圾建议」。

## 推荐流程

1. 垃圾建议 → 扫描 → 核对勾选 → 一键安全清理。
2. 大文件：占用 TopN / 浏览。
3. 重复文件：逐组确认后再删。
4. 软件卸载后看前后差异再清残留。

## 安全

- 默认进回收站；高风险项默认不勾选。
- MFT 极速扫需管理员且目标为盘符根（如 `C:\`）。
- 远程更新仅 HTTPS + SHA256。
