# disk-janitor（磁盘管家）

轻量、高速的 Windows 磁盘分析与清理工具。当前版本 **0.5.0**。

## 功能

- **总览**：各盘已用/可用（无需先扫盘）；上次扫描续扫、可回收估算、一键安全清理
- 扫描盘符 / 任意文件夹，显示真实占用（边扫边显示；大目录如 `node_modules` 估算计入并标注「未展开」）；取消扫描记住路径可续扫
- 左侧目录树、按大小/时间/名称排序、名称过滤、列表占比条；路径可打开位置 / 复制
- **最大占用** Top 40 + **空文件夹**；**按类型**筛选大文件（视频/安装包等）
- **垃圾建议**（Temp/浏览器缓存/缩略图/npm·pip·cargo 等；敏感项默认不勾选；仅勾选安全项 / 一键安全清理）
- **软件卸载** + **我已卸完再跟扫**（推荐闭环；粗扫仅 Program Files 且默认不勾；误报可加白名单）
- **开机自启** / **失效快捷方式** / **无效卸载注册表**
- **重复文件**（大小 + SHA256，可配置保留策略）/ **回收站清空** / **导出与对比基线** / **管理员提权**
- **设置**：UI 缩放、查重保留策略、扫描记忆
- **远程更新**：jiaoben `app-update` 三源择优；支持 SHA256 校验后热替换
- 删除默认 **仅回收站**；确认框可勾选「允许直接删除」并预览路径清单

## 运行

```powershell
cd E:\xiangmu\disk-janitor
.\start.cmd
```
